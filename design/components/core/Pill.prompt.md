One-line: states a row's answer to "does it run" — campaign lifecycle, game-day lifecycle, session state.

```jsx
<Pill tone="in">Confirmed</Pill>
<Pill tone="maybe">Quorum short</Pill>
<Pill tone="accent" dot>Poll open</Pill>
<Pill tone="idle">Unposted</Pill>
```

Pills are the one rounded shape in the system — everything else is square. Never use one as a button. Copy is the state itself, not a sentence: "Seating", "Locked", "Hiatus", "Concluded".
